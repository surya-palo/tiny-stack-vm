A complete, exact interpreter for make.fun's tiny stack ISA (v1) in one TypeScript file. Answers every instance in `/input/<id>/` into `/output/<id>/stdout.bin` + `exit.txt`.

Practice set: **1,000,000 / 1,000,000** (40/40). Plus 64 adversarial edge-case tests, all passing vs the reference VM. See [BUILD_LOG.md](BUILD_LOG.md). Entry for [make.fun](https://make.fun/competitions/tiny-stack-vm-01-run-20261122).
